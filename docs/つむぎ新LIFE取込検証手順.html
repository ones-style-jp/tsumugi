新LIFE取込検証 手順書

つむぎ → 新LIFE（国保中央会）へのCSV取込を、扇橋店の実データで確認する当日用の手順。Windows 11＋電子証明書のPCで実施。作成 2026-09-21

大事な前提　介護ソフトベンダ向けの「検証環境」は申請制（LIFE問い合わせフォームから申込→ヘルプデスクがアカウント発行）で、今日・明日には使えません。そのため新LIFEの本番に「まず利用者情報だけ」→「次に1名分の様式」の順で少しずつ入れて確認します。利用者情報の登録はどのみち移行に必須の作業なので、無駄にはなりません。同じ管理番号で再取込すると上書きされるので、やり直しもできます。

0. 前日までに（つむぎ側・扇橋店で）

A. 各種設定 → 事業所情報 → LIFE連携の欄（本日時点で扇橋は3つとも未設定）

項目入れる値どこで分かるか
介護保険事業所番号（10桁）指定通知書の事業所番号指定通知書／国保連請求の事業所番号。新LIFEのログイン後の事業所情報と一字一句同じである必要があります
サービス種類コード（2桁）15＝通所介護 ／ 78＝地域密着型通所介護指定を受けたサービス種別。定員18名以下なら地域密着型（78）が一般的。新LIFE側の事業所のサービス種類と一致させます
保険者番号（6桁・既定）利用者の被保険者証の「保険者番号」江東区の方が大半なら江東区の番号。別の保険者の方（住所地特例など）は、LIFE・加算画面の利用者ごとの欄で個別に上書き
CSVバージョン空欄のまま（自動で 0310）—
一体的取組該当しなければ「0：無し」口腔・栄養・機能訓練の一体的取組加算を算定していれば「1」
記入者の職種の既定値生活機能チェックを主に書く職員の職種例: 介護福祉士（170）・理学療法士（080）など

B. 利用者マスタの不足分を直す（LIFE・加算 → 「利用者情報CSV」の表にエラー行が赤く出ます）

本日時点の扇橋（利用中・休止 75名）で不足していたもの: 被保険者番号 2名生年月日 3名性別 1名要介護度 2名認定有効期間 2名（任意）

被保険者番号・生年月日・性別・保険者番号は介護保険証と照合されます（正確性チェック）。1文字でも違うと、その方の様式CSVもすべて登録できません。被保険者証を見ながら入力してください。

被保険者番号の桁数　扇橋75名のうち、マスタの被保険者番号が10桁の方は36名、6〜7桁の方が37名（Excel取り込みで先頭のゼロが落ちた可能性が高い）、未登録が2名です。つむぎは10桁未満を先頭ゼロで10桁にして出力し、その方の行に「要確認: 先頭ゼロで10桁にして出力します」と表示します。当日、6〜7桁の方を2〜3名、被保険者証の番号と見比べて、ゼロ埋めで一致するか確認してください（一致しない形式なら、その場で教えてください）。

B′. 他店舗の状況（参考・2026-09-21時点）

事業所番号・サービス種類コード・保険者番号は全店未設定。被保険者番号は 江古田（59名中6名未登録）以外の店舗はほぼ全員未登録（東小岩50/54・池上86/86・南水元46/49・水元67/72・西馬込60/62・柴又71/71・立石57/57）。評価記録（ADL・生活機能・機能訓練）は全店0件。扇橋で手順が固まってから、各店に「事業所情報の設定」と「被保険者番号の入力」を依頼する流れになります。

C. 様式テスト用に1名分の評価を入れる（扇橋はまだ評価記録が0件）

  1. LIFE・加算 → 利用者を1名選ぶ → 「一括評価」。
  2. 評価日・評価者、Barthel Index 10項目、身長・体重、口腔4項目（義歯／むせ／歯の汚れ／歯ぐき）を入力して保存。
  3. その方のフェイスシートで「障害高齢者の日常生活自立度」「認知症高齢者の日常生活自立度」を選んでおく（様式CSVの必須項目）。
  4. 提出ダッシュボードで「科学的介護推進」を選び、その方が✓ 提出可になっていることを確認。

1. 当日：つむぎでCSVを出す

  1. Windows PCでつむぎにログイン → 「LIFE・加算」。
  2. 「利用者情報CSV」の欄で エラー 0 を確認（残っていればマスタで修正）。→ 「利用者情報CSV出力」。ファイル名は 利用者情報_YYYYMM.csv。
  3. 提出ダッシュボードで様式「科学的介護推進」を選び、「利用者情報＋様式をまとめて出力」。提出可の方（まずは評価を入れた1名）の 利用者情報_YYYYMM.csv と TIFI2024_YYYYMM.csv が続けて保存されます。
  4. ダウンロード先（通常は「ダウンロード」フォルダ）にファイルがあることを確認。

CSVはメモ帳で開けますが、Excelで開いて保存しないでください（先頭のゼロが消え、被保険者番号が壊れます）。中身を見たいときはメモ帳で。

2. 当日：新LIFEに取り込む

  1. Edge または Chrome で https://top.life-kkh.jp/ を開く → 電子証明書の選択画面で事業所の証明書を選ぶ → ログイン。
  2. メニューから CSV取込（画面上の名称は「CSV取込」「一括登録」「外部データ取込」等）を開く。
  3. まず利用者情報CSVだけを選んで取込を実行 → 結果画面（登録件数・エラー一覧）をスクリーンショット。
  4. エラーが無ければ、様式CSV（TIFI2024）を選んで取込 → 同じく結果画面をスクリーンショット。
  5. 利用者一覧・様式一覧で、その方が登録されているか目視で確認。
順番の理由　新LIFEは利用者情報が登録されていない方の様式を受け付けません（仕様書4.5）。2つ同時に選んでも内部で利用者情報が先に処理されますが、切り分けのため分けて取り込みます。

3. 結果の見方と、そのとき私に送ってほしいもの

画面の状態意味対応
登録件数が出て、エラー0成功そのまま「4」へ
「正確性チェック」「介護情報基盤」「被保険者証と不一致」等のエラー保険者番号・被保険者番号・性別・生年月日のどれかが証と違う該当の方の被保険者証を見て利用者マスタを修正 → 利用者情報CSVを出し直して再取込
「利用者情報が存在しません」（様式側）利用者情報の登録が先に通っていない、または事業所番号／サービス種類コード／被保険者番号が利用者情報と一致していない利用者情報の取込結果を先に確認。事業所情報の設定値をLIFEの事業所情報と照合
「ファイル形式」「データ種別」「1行目」に関するエラーCSVの1行目（データ種別名）が合っていない可能性私に連絡（特にADL維持等のCSV。公式資料内で名称が2通り表記されているため、すぐ切り替えます）
「要介護度」「コード値」に関するエラーコード表の不一致私に連絡（エラー文をそのまま）
事業所番号／サービス種類コードに関するエラーつむぎの事業所情報がLIFE側の事業所と違う新LIFEの事業所情報画面の値をつむぎに合わせる

送ってほしいもの：①結果画面のスクリーンショット（成功でも） ②エラー文の全文（コピーでも写真でも） ③取り込んだファイル名。エラーの文面が分かれば、その場で直して出し直せます。

4. 成功したら（同日中でも可）

  • 扇橋の利用者情報CSVを全員分取り込む（もう一度「利用者情報CSV出力」→取込）。
  • 評価が済んでいる方から順に、様式ごとに「まとめてCSV出力」→取込。
  • 他店舗も同じ手順（各店の事業所情報の設定→利用者情報→様式）。
  • ADL維持等加算を出す店舗は、ADL維持等のCSVも1名分先に試す（データ種別名の確認のため）。
