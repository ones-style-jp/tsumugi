## 4. 版が混在する短い時間の注意

配信直後、まだ更新していない端末（1030h）が新しい端末と同時に動く時間がある。

- 申し送り（kind=memo）とタスク（kind=task）は、古い端末ではふつうの「予定」として見える。害はないが、古い端末でその予定を編集・保存すると kind が落ちることがある → 配信は朝一番にして、管理局「端末の更新状況」で全端末が 1121a になるのを当日中に確認する。
- 休止の履歴・フェイスシートの自立度・項目別同期は 1030h にも入っているので、混在しても巻き戻らない。
