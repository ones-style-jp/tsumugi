# LIFE・国保連の電子証明書を本部のパソコンへ移す手順

2026年11月19日 ／ 本部向け ／ 対象: 各店舗のパソコンに入っている電子証明書(LIFE・介護電子請求受付システムのログインに使うもの)

## 0. 先に知っておくこと

- 電子証明書は「その事業所として LIFE や国保連請求にログインできる鍵」です。ファイル(pfx)にして持ち出せるので、**USB は作業が終わったら中を消し、パスワードは紙で金庫に**入れてください。
- LIFE と電子請求受付システムの動作環境は **Windows + Edge または Chrome** です。本部で使うパソコンも Windows にしてください(Mac では動きません)。
- 1台のパソコンに9店舗分の証明書を入れることはできます。ログインのたびに「どの証明書を使うか」を選ぶ画面が出るので、**事業所番号を見て店舗を選びます**。
- 時間の目安: 1店舗 10分(控えのパスワードがそろっていれば)。9店舗で1時間半。発行時のパスワードが分からない店舗は再発行になり、別に1〜2週間かかります。

## 1. 店舗のパソコンで証明書を取り出す(エクスポート)

1. Windows キーを押して「**ユーザー証明書の管理**」と入力して開く(certmgr.msc という画面)。
2. 左の「**個人**」→「**証明書**」を開く。右に、発行先が店舗(事業所番号や事業所名)で、発行者が国保中央会(介護電子請求受付システム)の証明書があります。
3. その証明書を右クリック →「すべてのタスク」→「**エクスポート**」→「次へ」。
4. 「**はい、秘密キーをエクスポートします**」を選ぶ → 「次へ」。
   - ここが灰色で選べないときは、3章へ(この証明書は持ち出せない作り方で入っています)。
5. 形式は「**Personal Information Exchange - PKCS #12 (.PFX)**」。「証明のパスにある証明書を可能であればすべて含む」に**チェック**。「エクスポートが正常に完了したら秘密キーを削除する」は**チェックしない**。
6. 「パスワード」にチェックして、長めのパスワードを決める(12文字以上・店舗ごとに別)。**紙に書いて金庫へ**。
7. 保存先は USB メモリ。ファイル名は「店舗名_事業所番号.pfx」。→「完了」。「正しくエクスポートされました」と出れば終わりです。

## 2. 本部のパソコンに入れる(インポート)

1. USB の pfx ファイルをダブルクリック。
2. 「保存場所」は「**現在のユーザー**」→「次へ」→ ファイル名はそのまま「次へ」。
3. 1-6 のパスワードを入れる。「**このキーをエクスポート可能にする**」に**チェック**(将来また移せるように)。「すべての拡張プロパティを含める」はチェックのまま →「次へ」。
4. 「証明書の種類に基づいて、自動的に証明書ストアを選択する」→「次へ」→「完了」。「正しくインポートされました」と出れば終わりです。
5. 確認: 「ユーザー証明書の管理」→ 個人 → 証明書 に、入れた店舗の分だけ並んでいること。
6. 終わったら USB の pfx を削除し、ごみ箱も空にする。

## 3. 「秘密キーをエクスポート」が選べない店舗

- 発行のときに「持ち出し不可」で入れた証明書です。その店舗の「**証明書発行用パスワード**」(発行のときの通知に書かれたもの)があれば、電子請求受付システムにログインして同じ証明書を**もう一度ダウンロードして本部のパソコンに入れる**ことができます(店舗側はそのまま使えます)。
- 発行用パスワードも分からないときは、国保連の手続きで**再発行**(いまの証明書を失効させて新しく発行)になります。手数料がかかり、1〜2週間見てください。介護電子請求ヘルプデスク 0570-059-402。

## 4. ログインのときの選び方と注意

- LIFE や電子請求受付システムを開くと「証明書の選択」の小窓が出ます。**事業所番号を見て**その店舗の証明書を選びます。間違えると別の店舗としてログインされます。
- Edge や Chrome は、一度選んだ証明書をブラウザを閉じるまで覚えます。**店舗を変えるときは、ブラウザの窓を全部閉じてから開き直す**と、選ぶ画面がもう一度出ます。
- 本部のパソコンは、Windows のログインにパスワードを付け、席を離れるときは画面をロックする(Windows キー + L)。担当者が退職するときは証明書を削除する。

## 5. 費用の目安(2026年11月時点・国保連の案内で最終確認を)

| 項目 | 費用 |
| --- | --- |
| 介護保険の電子証明書(新規・更新) | 1事業所あたり 13,200円(税込)で3年 |
| 代理人(本部)の電子証明書 | 同額で1枚。委任した全事業所の請求に使える |
| LIFE の利用料 | 無料 |
| 国保連請求の代理人(本部が同一法人として)の手数料 | 国保連側の手数料は無し。証明書代だけ |
| 国保中央会の介護伝送ソフト | 使う場合は有料。つむぎから CSV を出して電子請求受付システムに直接出す形なら不要(要確認) |

## 6. 今後の楽な形(案)

- 国保連請求は、本部が「代理人」になれば証明書1枚で全店の請求ができます(本部の手順書「国保連請求の代理人申請」参照)。LIFE に代理人の証明書で入れるかは未確認なので、ヘルプデスクに確認してから決めます。
- LIFE の提出は、店舗ごとに証明書が要る間は、店舗のパソコンで店舗の職員が「つむぎで CSV を出す → LIFE に上げる」(1店3分)をするのが、本部に集めるより負担が分散します。本部は「出したか」をつむぎの画面で見るだけにします。
