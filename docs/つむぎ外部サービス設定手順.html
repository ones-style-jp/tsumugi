つむぎ 外部サービス設定手順

Claude（AI）のAPIキー登録と、Vercel・Supabase の初期設定 ／ 2026年9月17日

いまの状況
外部サービスを本部で一括管理する仕組みは実装・配信済みです。ただしキーがまだ未登録のため、現在は全店でAI機能が使えません。下の手順で設定すると使えるようになります。所要時間は10〜15分です。

全体の流れ

設定は3回の作業で終わります。1回目と2回目は最初だけ、3回目以降はつむぎの管理局画面だけで完結します。

  1. Supabaseで「キーの保管庫」を作る（SQLを1回貼り付けて実行）
  2. Vercelで「合言葉」を1つ登録する（管理局画面から設定を変更するための鍵）
  3. つむぎの管理局で、Claude のAPIキーを登録する

作業1: Supabase でキーの保管庫を作る

なぜ必要か: APIキーを、ブラウザから読めない安全な場所に保管するためです。つむぎの通常のデータ置き場は、アプリを開ける人なら読めてしまうため、キーを置けません。

  1. supabase.com/dashboard を開き、つむぎのプロジェクトを選びます。
  2. 左メニューの SQL Editor をクリックし、New query を押します。
  3. 下の内容をまるごとコピーして貼り付け、右下の Run を押します。
create table if not exists public.app_secrets (
  key        text primary key,
  value      text not null,
  updated_at timestamptz not null default now(),
  updated_by text
);

alter table public.app_secrets enable row level security;

revoke all on public.app_secrets from anon;
revoke all on public.app_secrets from authenticated;
成功の目安: 「Success. No rows returned」と出れば完了です。エラーが出た場合はその文言をお知らせください。

※ このSQLは、保管庫を作り「サーバー以外からは一切読めない」鍵をかけるものです。同じファイルは docs/sql/app_secrets.sql にも入っています。

作業2: Vercel で合言葉を登録する

なぜ必要か: 管理局の画面からキーを変更するときの本人確認に使います。この合言葉を知っている人だけが設定を変更できます。

  1. vercel.com/dashboard を開き、tsumugi のプロジェクトを選びます。
  2. 上部の Settings タブ → 左メニューの Environment Variables を開きます。
  3. Key の欄に ADMIN_API_SECRET と入力します（大文字・アンダースコアまで正確に）。
  4. Value の欄に、本部だけが知る合言葉を自由に決めて入力します。
    例: tsumugi-honbu-2026-9x7k のような、推測されにくい20文字前後の文字列
  5. Environments は Production・Preview・Development の3つすべてにチェックを入れます。
  6. Save を押します。
  7. 上部の Deployments タブを開き、一番上の行の右端「…」→ Redeploy を押します。
    ※ 環境変数は、再デプロイしないと反映されません。1〜2分で終わります。
決めた合言葉は必ず控えておいてください。紛失した場合は同じ手順で設定し直せます。

作業3: 管理局で Claude のAPIキーを登録する

  1. console.anthropic.com にログインし、左メニューの API keys → Create Key で新しいキーを作ります。
    表示された sk-ant-api03-... をコピーします。この画面を閉じると二度と表示されません。
  2. つむぎに本部アカウントでログインします（店舗を選ぶ前の「つむぎ管理局」の画面です）。
  3. 外部サービス設定（全店共通・AI / マップ / メール / FAX） を開きます。
  4. 合言葉の欄に、作業2で決めた文字列を入れて 設定を読み込む を押します。
  5. Claude（AI） の APIキー 欄にコピーしたキーを貼り付け、登録 を押します。
  6. 同じ行の 接続テスト を押して「✓ AIが応答しました」と出れば完了です。
反映まで最大1分かかります。その後、全店舗でAI機能（モニタリングの下書きなど）が使えるようになります。

Vercelの環境変数で設定済みの項目は、画面上で「Vercelの環境変数」と表示され、誤操作を防ぐため画面からは変更できません。画面で管理したい場合は、Vercel側の項目を削除してから登録してください。

もうひとつの方法（管理局を使わない場合）

作業1・2を省いて、Vercelの環境変数に直接キーを入れる方法でも動きます。作業2と同じ手順で、Key を ANTHROPIC_API_KEY、Value を sk-ant-api03-... にして保存し、再デプロイするだけです。

ただしこの場合、キーを変更するたびにVercelでの操作と再デプロイが必要になります。管理局から変えられるようにしておく方が、日々の運用は楽です。

安全のためのお願い

使わなくなったキーは、必ず発行元で無効化（Revoke）してください。
つむぎ側から削除しても、すでに外部に渡ったキーは止まりません。Anthropicのコンソールでは、API keys の一覧から該当キーの「…」→ Delete で無効化できます。

キーをメール・チャット・スクリーンショットで送らないでください。登録は、この手順のように画面へ直接貼り付ける形でお願いします。
