# つむぎ LP（/lp.html）イラスト差し替え手順とプロンプト

LP の 2 か所に、いま簡易な線画（SVG）が入っています。ChatGPT 等で生成したイラストを下記のファイル名で `public/lp/img/` に置き、`lp.html` の該当ブロック（`data-illust="hero"` / `data-illust="saigai"`）の `<svg>…</svg>` を `<img src="/lp/img/○○.png">` に差し替えれば反映されます（差し替えはご依頼いただければこちらで行います）。

共通のトーン: やわらかいフラットイラスト、線は細め、色は「つむぎ」の緑（#4f7a2a／薄緑 #eef5e4）と生成りの背景（#f7f8f3）、差し色に琥珀（#b7791f）。人物は日本人、写実ではなく親しみやすい絵柄。文字は入れない。背景は単色または淡いグラデーション。

## 1. ヒーロー（hero.png・横 1200 × 縦 900 px・PNG）

```
やわらかいフラットイラスト。60代くらいの日本人女性が自宅のリビングでソファに座り、スマートフォンを両手で持って画面を見ながら、安心した穏やかな笑顔を浮かべている。画面には小さく折れ線グラフと笑顔マークが見える。窓の外は夕方の光。遠くに小さく、デイサービスの建物と、そこで体操をしている高齢の男性の様子が、ふきだしのように描かれている。配色は緑（#4f7a2a）と薄緑（#eef5e4）、生成り（#f7f8f3）を基調に、差し色に琥珀色（#b7791f）。線は細く、影は控えめ。文字は入れない。背景は淡い単色。横長 4:3。
```


## 生成後のチェック

- 実在の人物・施設に見える描写がないこと（架空の人物・建物）
- 文字が入っていないこと（入っていたら「文字を消して」と再生成）
- 背景が LP の生成り色（#f7f8f3）となじむこと（真っ白でも可）
