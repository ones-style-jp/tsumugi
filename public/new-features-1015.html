送迎表と日誌：新しい1日の流れ

送迎のことは送迎表で決めて、日誌はそれを取り込みます。送りが迎えと同じ日は、2の座席表は使わなくてかまいません。

前の週まで

1. 迎えを作って確定

送迎表の「前週コピー」「自動計算」で、車・乗る順・お迎え時間を作り、「確定」します。到着の時間には「目安」が入ります。

送りの前

2. 送りを座席表で

送りを変える日は、「送りは迎えと同じ」のチェックを外して座席表で席・順番・運転者・出発時間を決めます。必要なら座席表をダウンロードして印刷。

迎えから戻ったら

3. 施設に着いた時間

確定後の表示（パソコン・iPad。スマホは上の「1週間」を押した表示）で、各車の「施設に到着」を実際の時間に直します。

日誌

4. 送迎表取込

日誌の「送迎表取込」を押します。車・運転者・到着・出発が入ります。確認が出たら答えて、保存します。

使う前に確かめてください（店舗で1回だけ）

設定場所使われるところ
サービス提供時間（1単位目・2単位目。例 9:00〜12:05）各種設定 → 事業所情報送迎表の自動計算（開始の1分前に着く）、到着・出発の確認（日誌・送迎表）、出発の目安
送迎車両の名前・定員（運転者を除く人数）各種設定 → 日誌 → 送迎車両座席表の席の形。定員が無い車は、席の絵が正しく出ません
乗車にかかる時間（分）・送迎時の連絡先利用者マスタ → サービス提供内容自動計算のお迎え時間、座席表の出発の目安／スマホの1日リストの電話
職員の名前各種設定 → 日誌 → 職員送迎表で選んだ運転者と同じ名前の職員に、日誌でチェックが付きます

送迎表を使わない店舗は

各種設定の「送迎表を使う」のチェックを外すと、送迎表まわりの表示（ホームのお知らせ・日誌の「送迎表取込」など）が出なくなります。日誌はこれまでどおり手で入れてください（「1週間前の送迎を自動コピー」も使えます）。

確定のあとに変わったら

休み・時間の変更などは、上の「変更内容」で確かめられます。ご家族への連絡が必要なものは、連絡したら「連絡済」にチェックを付けます（6ページ）。

送迎表：送りを「座席表」で決める

紙の座席表（車の絵に名前を書いて、送りの順番を決めるもの）と同じことを、画面でできます。

使い方

  1. 送迎表で、その日の「送りは迎えと同じ」のチェックを外します。座席表が開きます（迎えの逆の順で、下書きが入っています）。
  2. 名前を長押ししてつかみ、席に入れます。入れた順に丸い番号が付きます。これが送りの順番です。
  3. 別の席に入れると入れ替わります。席から外すときは、上の「席が決まっていない方」へ落とします。
  4. 運転席で送りの運転者を選びます。
  5. 車の名前の横の「出発」を押して、出発時間を入れます（次のページ）。
  6. 車の下のメモ欄に「前・横」などを書けます。
  7. 上の「AM送り」「PM送り」で切り替え、◀ ▶で日を変えます。終わったら左上の「閉じる」。もう一度開くときは、チェックの横の「座席表」を押します。

覚えておくと便利なこと

  • 車に乗るのは席に入っている方だけなので、定員を超えることはありません。
  • 確定した週でも、送りは変えられます（迎えは確定のまま）。確定後の表示の「送りは迎えと同じ」「座席表」から開きます。
  • AM送りの座席表の下には、その日の午後の迎え（車・運転者・お迎えの方と時間）が見えます。午前に送って、そのまま午後のお迎えに行くときの確認に使えます。
  • 「ダウンロード」で、その日のAM送り・PM送りをA4の座席表にできます。運転者と出発時間も載ります。

送りを迎えと同じに戻すとき

「送りは迎えと同じ」にもう一度チェックを付けます。座席表で決めた送り（席・順番・メモ）は消えるので、確認が出ます。

送迎表：送りの順番・出発時間・座席の並び

送りの順番を並べ替える

  1. 席の丸い番号を押します。その車に乗る方が、送りの順番どおりに一覧で出ます。
  2. 名前をつかんで上下に動かすか、右の矢印（∧ ∨）で入れ替えます。
  3. 終わったら「閉じる」を押します。

全員の並びを見ながら直せます。1人を動かすと、ほかの方の番号も変わるので、一覧で確かめてください。

出発時間を入れる

  • 車の名前の横の「出発」を押すとテンキーが出ます。パソコンはキーボードでも入力でき、Enterで決定です。
  • テンキーの「目安 ○:○○ を入れる」を押すと、目安の時間が入ります。目安は、終了時刻（例 12:05）に、乗る方の「乗車にかかる時間」を足した時間です（設定していない方は1分で数えます）。
  • 座席表の上の「出発の目安を入れる」を押すと、全部の車にまとめて目安が入ります。自分で入れた出発時間は変わりません。
  • 終了時刻より前の時間を入れると、「このまま登録してよろしいですか？」と出ます。

座席の並びを車に合わせる（送迎表の「設定」）

  • 席の形は、車の定員（運転者を除く）から自動で作ります。1列目は運転席と助手席です。
  • 同じ定員でも、2列目が3席の車と、3列目が3席の車があります。実際の車と違うときは、送迎表の「設定」→「座席表の並び」で選んで「保存」します（例：2列目 3席・3列目 2席）。
  • 定員はここでも、各種設定→日誌の送迎車両でも直せます（同じ項目です）。
  • 設定画面には、自動計算で施設に着く時間も表示されます（次のページ）。

送迎表：「施設に到着」の時間と自動計算

迎えの各車の、最後の方の下に「施設に到着」の欄が付きました。ここに入れた時間が、日誌の到着時間に入ります。

施設に着く時間は「開始時間の1分前」

  • 自動計算のお迎え時間は、事業所情報の1単位目・2単位目の開始時間の1分前に施設へ着くように計算します（9:00開始なら 8:59、13:20開始なら 13:19）。
  • 送迎表の設定にあった「到着目標時刻」はなくなりました。
  • 事業所情報の時間が入っていないと、自動計算の画面に「未入力」と出て計算できません。各種設定 → 事業所情報で、サービス提供時間（例 9:00〜12:05）を入れてください。

「目安」と、実際の時間の入れ方

  1. 自動計算をすると、到着に「目安」が入ります（薄い文字・点線の枠・「目安」の札）。前週コピーでは、前の週の時間が目安として入ります。
  2. 迎えから戻ったら、「施設に到着」の時間を押します。テンキーが出るので、実際に着いた時間を入れて「決定」。
  3. 自分で入れると「目安」ではなくなり、あとで自動計算をしても変わりません。

開始時間を過ぎた到着を入れると「このまま登録してよろしいですか？」と出ます。確定後の表示でも入れられるので、当日はiPadからでも直せます。スマホは、上の「1週間」を押して出る表示から入れられます。

送迎表：そのほかの変更

確定のあとの変更は「変更内容」で

  • 日付・午前／午後で絞り込めます。
  • ご家族への連絡が必要な変更には「要連絡」が付きます。連絡したら「連絡済」にチェック（全部の端末で同じ表示になります）。
  • 項目を押すと、送迎表のその方が黄色で表示されます。
  • 確定のあとに休みになった方は、元の車の位置に取り消し線で残ります。
  • 「確定済」のメニューは「確定を更新」「確定を解除」だけです。直すときは確定を解除してから直し、もう一度「確定」します。

時間を入れると、乗る順が時間順に

お迎え時間を入れると、その車の乗る順が自動で時間順にそろいます。入力画面・運行表（印刷）・スマホの1日リストで順番がずれません。

運行表（ダウンロード）

運転者の位置・車名の大きさ・休みの方の名前などを見やすくしました。色の意味は「時間の赤枠＝時間変更／緑＝振替／水色＝初回」です。未割当の欄は、徒歩（オレンジ）と見分けやすい赤みの点線になりました。

送迎時の連絡先

利用者マスタ → サービス提供内容の「送迎時の連絡先」で、送迎のときに電話をかける相手（本人・緊急連絡先・別の相手）を選べます。スマホの1日リストでは、その番号がいちばん前に出ます。

前週コピー・自動計算・確定

確定した週で「休み・休止になった方を反映」を押すと、確定が自動で解除されて作成中に戻ります。直したら、もう一度「確定」してください。

スマホは見るための画面です。直すときはパソコン・iPadで行ってください（施設に到着の時間は、上の「1週間」を押して出る表示から入れられます）。

日誌：送迎表取込で送迎の欄が埋まる

送迎表取込のしかた

  1. 日誌で日付とAM／PMを選び、「送迎表取込」を押します。
  2. 「取り込みます。よろしいですか？」と出たら「OK」。
  3. 迎え・送りの車、運転者、到着・出発の時間が入ります。
  4. 確認が出たときは、下の表を見て答えます。
  5. 内容を見て「保存」します。

こんな確認が出たら

出る確認答え方
「目安」のままの時間があります送迎表の到着・出発が見込みのままです。そのまま入れてよければ「OK」。実際の時間を入れるなら「キャンセル」して、送迎表か日誌で直す。
日誌の時間と、送迎表の時間が違う車があります送迎表の時間で上書きするなら「OK」。日誌の時間のままにするなら「キャンセル」。

「1週間前の送迎を自動コピー」を使っている店舗

その日の送迎表がある日は、コピーしません。「送迎表取込」で入れてください。送迎表が無い日は、これまでどおりコピーされます。

運転者にチェックが付かないとき

送迎表で選んだ運転者と、日誌の職員の名前が同じときだけチェックが付きます。名前（漢字・空白）がそろっているか確かめてください。

時間の確認

到着が提供時間の開始（例 9:00）を過ぎるとき、出発が終了（例 12:05）より前のときは、「このまま登録してよろしいですか？」と出ます。テンキーにも「9:00 までに到着」と出ます。

兼務（副役職）の方

例：生活相談員で、管理者がいない日だけ管理者も兼ねる方。本来の役職の欄を押すと出勤だけ。その日に管理者も兼ねるときは、管理者の欄の名前も押します。

10月15日より前の日誌は、これまでどおりの見え方です。

サービス提供記録 入力

気分のあとは「特記に書く内容」

  1. 「通所」「帰宅」の気分を押して、絵文字を選びます。
  2. 「特記に書く内容」に、気づいたこと（例：昨夜はよく眠れたとのこと）を入れます。空のままでもかまいません。
  3. 「決定」で特記欄に入ります。もう一度入れ直すと、前の内容と置き換わります。

理由を選ぶ画面はなくなりました。iPad・スマホはキーボードのマイクで音声入力できます。

利用者の並び替え

  1. 「AM／PM」の横の「並び替え」を押します。
  2. 名前を長押しして上下に動かすか、「上へ」「下へ」で並べ替えます。
  3. 「この順で保存」を押すと、表がこの順になります。

並び順は店舗の全部の端末で同じです。欠席・休止の方は、これまでどおり下にまとまります。「あいうえお順に戻す」で元に戻せます。

血圧の再測定

再測定の控えのボタンは「削除」ではなく「戻す」になりました。押すと、その回の値が欄に戻ります（今の値は消えます）。

テンキー

  • テンキーが出ているマスをもう一度押すと閉じます（入れた値は残ります）。
  • 数字の並びを電話型（1 2 3 が上）／電卓型（7 8 9 が上）から選べます。各種設定 → システム（端末ごとに覚えます）。
  • 基準値に数字が無い運動に○を入れようとすると、「数値を入力してください」と出ます。

初回ご利用報告

「ご利用の様子」に、初回の提供記録の特記が最初から入ります（ここで直しても、提供記録の特記は変わりません）。

いいえ。送りが迎えと同じ日は、「送りは迎えと同じ」にチェックを付けたままで大丈夫です。送りの車や順番を変える日だけ、座席表を使ってください。
送迎表の到着時間が、薄い文字で「目安」と出ています。
自動計算や前週コピーで入った見込みの時間です。迎えから戻ったら、押して実際の時間に直してください。直すと普通の文字になります。
自動計算を押すと「サービス提供時間が未入力です」と出ます。
各種設定→事業所情報の「1単位目・2単位目」のサービス提供時間（例 9:00〜12:05）を入れてください。施設に着く時間は、その開始の1分前で計算します。
送迎表の設定に「到着目標時刻」が無くなりました。
施設に着く時間は、事業所情報の開始時間の1分前にそろえました。2か所で設定して食い違うことがなくなります。
送迎表取込をしても、時間が入らない車があります。
日誌にすでに違う時間が入っていると、上書きするかを聞かれます（キャンセルすると日誌の時間のまま）。送迎表の時間が「目安」のままの車は、「OK」を押したときだけ入ります。
送迎表取込で、運転者にチェックが付きません。
送迎表で選んだ運転者と、日誌の職員の名前が同じ方にだけ付きます。名前をそろえてください。
日誌の「1週間前の送迎を自動コピー」が入らなくなりました。
その日の送迎表がある日はコピーしない形にしました。「送迎表取込」（ボタンに「未取込」と出ます）で入れてください。
兼務の人の、管理者の欄にチェックが付かなくなりました。
本来の役職の欄は出勤だけを表します。その日に管理者も兼ねるときは、管理者の欄の名前も押してください。
気分の理由を選ぶ画面がありません。
絵文字を選んだあとに「特記に書く内容」を入れる形に変わりました。入れた内容は特記欄に入ります。
利用者マスタに「削除」ボタンがありません。
管理者だけに出るようにしました。削除が必要なときは管理者に頼んでください。

直った不具合（主なもの）

  • 日誌：兼務の方を押すと、本来の役職と副役職の両方にチェックが付く／欠席・休止・休業の方が載らないことがある
  • スマホ：休み連絡で名前が潰れる／休み連絡・各種連絡のダウンロードが小さくなる／提供記録の罫線が見えない／向きを変えるとエラーになる
  • 連絡帳：再検で血圧を空にして脈だけ入れたとき、1回目の血圧が混ざる
  • 個別運動：「未設定」にしても戻る・削除した運動が残る・「15秒×2」などが見切れる
  • 利用者マスタ：開始日が先の休止が、すぐに休止扱いになる／既往歴が古い内容で上書きされることがある
  • 長い時間開いたままにすると「エラーコード5」で落ちることがある
