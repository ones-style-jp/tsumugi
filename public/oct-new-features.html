つむぎ 10月からの新機能（エリア担当者向け）1

送迎表 全店

できるようになったこと

  • 「この週を完成にする」：週の送迎表を確定します。完成後に車・乗車順・時間・運転者を変えると、その方に赤丸（●）が付き、変更の件数が出ます。赤丸は「ご家族へ電話連絡が必要か」の目印です（凡例：●＝時間変更（要TEL））。
  • 未割当の方の「移動先…」：名前の右の選択から、車・徒歩・その他へ移せます（長押しで動かす操作も使えます）。
  • 週間の配車＋時間計算：近所ごとに車を分け、Googleマップでお迎え時間を計算します。お迎え時間は到着目標の時刻から逆算します（出発時刻の設定は使わないことにしました）。
  • 時間の精度：待ち合わせ場所（玄関前など）が入っている方も、Googleには住所だけを送ります。住所に都道府県が無いときは事業所の都道府県・区市町村を補います。
  • 前週コピー：前の週に振替で来た方、この週にお休みの方はコピーしません。
  • 提供記録との連動：サービス提供記録で「振替」「臨時」にした方も送迎表に出ます（月間スケジュールに印が無くても）。欠席・休止も反映されます。
  • 日誌へ取り込み：日誌の「送迎表取込」で、送迎表の車の割り当てを日誌の迎え・送りに入れられます。

店舗へのひと言

9月30日より前に計算した週でお迎え時間が早すぎる方がいたら、その日の「時間のみ計算」を押し直してもらってください（待ち合わせ場所の影響で移動時間が長く出ていた不具合を直しました）。

ご家族・ケアマネ画面の「お迎え時間」 全店

表示のしかた

  • ご家族・ケアマネ・ご本人の画面の「通所記録」の上部に、「本日のお迎え時間」（利用日の開始前）または「次回のお迎え時間」を大きく表示します。分析（個人）にも同じ枠が出ます。
  • 時間は次の順で決まります：
    ① 送迎表の乗車時間 → ② 前回の連絡帳の「次回予定」 → ③ 利用者マスタの曜日ごとの送迎時間
  • 送迎表を完成にした後で時間や送迎方法（車／徒歩）が変わると、「お迎え時間が変更されました（9時00分 → 9時15分）」と表示します。
  • 送迎表の「分」が空欄のときは「13時　分」と表示します（「13時頃」とは出しません）。前日・当日なのに分が未設定のときは、ご家族に事業所へ確認していただく案内が出ます。
  • 利用日の開始前は「本日のご利用予定　○時○分から」も表示します。

災害速報 全店

  • ホームの災害速報を、事業所の住所（区市町村・沿岸の予報区）に関係するものだけに絞りました。
  • 遠い地域の「津波予報（若干の海面変動）」、他の地域の地震、都内の島しょ部の警報などは出ません。
  • 事業所の住所は「各種設定 → 事業所情報」の住所を使います。住所が正しく入っているか店舗でご確認ください。

分析 全店

  • 分析（稼働）の介護度内訳：介護度が未入力の方を「未設定」として表示し、割合の合計が100％になるようにしました。
  • 欠席理由ランキング：理由と内訳を省略せず、全文を折り返して表示します。

サービス提供記録入力 全店

血圧・脈の「再」ボタン

  • 測り直したときは血圧欄の横の「再」を押します。それまでの値が「1回目」として欄の下に残り、欄が空になるので、いつもどおり新しい値を入力します。
  • 残した値は1件ずつ削除できます。印刷の特記にも「開始 1回目 …」として残ります。

個別機能訓練の実施担当（個別機能訓練加算の設定がある店舗）

  • 上部の選択で、表示中の午前／午後の全員の実施担当をまとめて設定します。人ごとに変えるときは「利用者ごと」で。既定は担当職員の最初の機能訓練指導員です。自動保存されます。
  • 印刷の日付欄に「記録：○○　個別：○○」と1行で出ます。
  • 先週の割り振りをコピー（同じ曜日・同じ午前／午後）と、リセット（全員を「グループなし」へ戻す。実施担当はそのまま）があります。
  • 上部の人数表示は「出席 → 欠席 → 振替 → 臨時 → 休止 → 休業」の順に2行でまとめました。

日誌 全店

必須職員のチェック

  • 定員に応じて必要な職員（管理者・生活相談員・機能訓練指導員・看護職員・介護職員）が担当職員に選ばれていないと、「必須職員未選択：○○」と表示し、日誌は未完成のままになります。
  • 兼務：担当職員の中から、別の役職の人がその役職を兼ねたことにします（例：看護師が機能訓練指導員を兼務）。警告が消えます。
  • 減算（看護職員・介護職員）／加算なし（機能訓練指導員）：その職員が不在だった日を記録して警告を消します。記録は日誌の外（赤い帯）に表示され、印刷には出ません。

そのほか

  • 上部のボタンを「担当者追加 → 送迎表取込 → 迎え → 送り → プレビュー → 保存」の順に並べました。
  • 「送迎表取込」で、送迎表の車の割り当てを迎え・送りに取り込めます。
  • 欠席・休止の方に車の割り当てが残っていても、送りで誰も乗らない車はグレーアウトされ、未完成扱いになりません。
  • 日誌の「担当者追加」は、いつもその日だけの追加です（各種設定の担当職員は変わりません）。

店舗へのひと言

「必須職員未選択」が出たら、まず担当職員のチェック漏れがないかを確認し、本当に不在だった日だけ「減算」「加算なし」を押すようお伝えください。

連絡帳 全店

  • 空印刷：氏名・記録・次回予定が空欄の連絡帳を、印刷設定の用紙（B5横2面／B6縦／B5横1面）と位置のとおり、指定の枚数だけ印刷します（手書き用）。
  • 印刷位置の微調整：プレビューの矢印を1回押すと1mm動きます。押すと設定に保存され、その場でプレビューが組み直されます。
  • 利用者ごとの値：項目設定で「利用者ごと」をONにした項目は、その画面で利用者一覧に直接入力できます（空欄の方は共通の値）。
  • 連絡事項：ボタンに入力済みの人数（個別○名／全員）を表示し、利用者の選択では入力済みの方を先頭に「● 氏名（入力済）」と出します。
  • 血圧の設定が「開始時のみ」の店舗は、2行目が「終了時」ではなく「再測定」になります（開始時＝1回目、再測定＝最新の値）。

モニタリング 全店

  • 確定したらすぐ反映：「確定」を押した時点で、分析（個人）とケアマネの画面に反映します（これまでは対象月の最終日18時以降）。確定を解除すると取り下げます。
  • ケアマネへのお知らせ：担当ケアマネのお知らせに「モニタリング（○月）を作成しました」を自動で出します。
  • ケアマネ閲覧済とFAXの省略：「担当ケアマネへFAX」「自動FAX送信」のとき、つむぎで閲覧済みの方を省くか確認が出ます（FAX代の節約）。
  • 実施日：確定した日を実施日にします（これまでは下書きを作った日のままでした）。
  • 休止中の方：月の途中で休止にした方も一覧に出ます。その月に通所があれば「通所あり」、なければ「通所なし」に「休止中」の印付きで出ます。

店舗へのひと言

つむぎに登録済みのケアマネには、確定と同時に表が届きます。閲覧済みになった方はFAXを省けますが、まだ見ていない方には従来どおりFAXを送ってください。

ご家族・ケアマネの登録と画面 全店

  • 「お知らせ・閲覧管理」のプレビューは「家族・ケアマネ画面プレビュー」になり、ご家族／ケアマネを切り替えて確認できます。
  • ケアマネが交代したら、アカウント管理には今の担当ケアマネだけを表示します（前任は件数のみ）。
  • 登録メールの反映：ご家族が登録したメールアドレスをフェイスシートの連絡先に表示します。ケアマネが登録したメールは「ケアマネ事業所・担当者」のメール欄へ自動で入ります（空欄のときだけ）。
  • 招待コードの安全対策：招待コードの確認をサーバーで行い、間違いが続くと一時的に入力できなくなります（同じ回線で15分に5回まちがえると15分停止、など）。偽の招待URLで登録できる穴もふさぎました。
  • 招待コードの有効期限は3日・1回限りです（これまでどおり）。

各種設定 全店

  • 担当職員：管理者・生活相談員・機能訓練指導員・看護師・介護職員（＋店舗で追加した役職）の枠に分けました。副の役職（兼務）と資格を2つまで選べます。
  • 気分の入力：OFFにすると、提供記録入力・印刷・分析・ご家族画面から気分の欄が消えます（入力済みの気分は消えません）。
  • 血圧・脈の測定：「開始時＋終了時」「開始時のみ」を選べます。開始時のみの店舗は終了時の列を出しません。
  • 利用者マスタの個人ファイルは、画面いっぱいの大きさで開くようにしました。

店舗から聞かれそうなこと

新しいボタンが出てこない
アプリを一度閉じて開き直してもらってください（ホーム画面に追加したアプリは、完全に終了してから開く）。それでも出ない場合は本部へ。なお試験版の機能は、扇橋店以外ではまだ出ません。
送迎表の赤丸（●）は何ですか
「この週を完成にする」を押した後で、時間・車・乗車順・運転者が変わった方の目印です。ご家族への電話連絡が必要かどうかの確認に使ってください。
お迎え時間が早すぎる（遅すぎる）方がいる
まず利用者マスタの住所が番地まで正しいか確認し、その日の「時間のみ計算」を押し直してください。待ち合わせ場所（玄関前など）は時間の計算には使いません。
ご家族の画面のお迎え時間が「13時　分」になっている
送迎表の「分」が空欄です。送迎表で分まで入れれば、ご家族の画面も直ります。
ご家族の画面に「お迎え時間が変更されました」と出た
送迎表の完成後に時間や送迎方法が変わったためです。念のためご家族へお電話でもお伝えください。
モニタリングのFAXはもう送らなくてよいですか
つむぎに登録済みで「ケアマネ閲覧済」になった方は省けます（FAX送信のときに確認が出ます）。未登録・未閲覧のケアマネには従来どおりFAXを送ってください。
日誌に「必須職員未選択」と出て完成しない
担当職員のチェック漏れがないか確認してください。別の役職の人が兼ねた日は「兼務」、本当に不在だった日は「減算」「加算なし」で記録すると警告が消えます。
ご家族が招待コードを入れたら入力できなくなった
まちがいが続いたための安全対策です。15分ほど待ってから、正しいコードで入れてもらってください。有効期限（3日）が切れている場合は新しいコードを発行します。
災害速報が前より出なくなった
事業所の地域に関係するものだけにしたためです。各種設定 → 事業所情報の住所が正しいか確認してください。
気分の欄を使っていない
